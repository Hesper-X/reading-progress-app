# 读书进度条 V3.4.0 用户手册

---

## 一、软件简介

「读书进度条」是一款专注于阅读进度管理的移动应用。它帮助你记录每一本正在读的书、标记已完成的阅读、看到自己的阅读统计数据和年度趋势，把读书变成一种可视化的"生命进度"。

**核心功能：**
- 📚 添加在读/已读/想读书籍
- 📊 阅读统计与年度趋势图表
- ✅ 每日打卡与连续记录
- 📝 读后笔记与星级评价
- 📤 生成阅读分享卡片
- 🌙 支持深色/浅色主题
- 🔔 每日阅读提醒
- 🏆 Pro 版解锁高级功能

**适用平台：** Android / iOS

**软件版本：** V3.4.0

---

## 二、安装说明

### Android 安装
1. 下载 APK 安装包
2. 在设备设置中允许「安装未知来源应用」
3. 点击 APK 文件完成安装
4. 首次启动建议授予通知权限（用于每日阅读提醒）

### iOS 安装
1. 通过 App Store 搜索「读书进度条」下载
2. 首次启动允许通知权限

## 三、主要功能操作

### 3.1 首页（当前在读）

打开应用后，首页展示「当前在读」的书籍列表。

- **书籍卡片**：每本书显示书名、作者、封面、阅读进度
- **搜索书籍**：点击首页搜索按钮，可通过拍照识别书名或手动搜索添加书籍
- **标记读完**：点击书籍卡片进入详情页，可标记读完并记录读后笔记

### 3.2 添加书籍

支持三种方式添加书籍：

1. **拍照识书**：点击「拍照识别」按钮，使用 OCR 技术识别书籍封面文字，自动填充书名
2. **搜索添加**：在搜索框输入书名关键词进行搜索
3. **手动输入**：直接输入书名和作者信息

添加时可选择：
- 「加入想读」— 加入心愿书单
- 「开始阅读」— 立即开始计时阅读

### 3.3 书架（全部书籍）

书架页面展示所有已添加的书籍，支持：
- 按状态筛选：在读 / 已读 / 想读
- 按分类筛选
- 搜索书籍

### 3.4 标记读完

在读列表中点击任意书籍，进入详情页：
1. 点击「标记读完」按钮
2. 填写读后笔记（可选）
3. 给出星级评价（1-5星）
4. 选择读完日期
5. 确认保存

完成后该书籍自动转移到「已读书架」。

### 3.5 阅读统计

统计页面提供多维度的阅读数据可视化：

- **年度阅读量**：本年已读书籍总数
- **阅读趋势图**：按月展示阅读数量的变化折线图
- **最爱作者排行**：按阅读数量排序的作者榜单
- **最长与最短书籍**：本次阅读时长的两极
- **阅读偏好分布**：书籍类型的饼图分析

### 3.6 每日打卡

在首页点击「打卡」按钮进入日历打卡界面：
- 日历视图按月份展示打卡记录
- 已打卡日期以标记显示
- 查看连续打卡天数和总打卡次数
- 可对当天进行打卡（每日限一次）

### 3.7 分享功能

统计页面右上角可进入分享功能，生成精美的阅读数据分享卡片：
- 卡片包含年度阅读数据摘要
- 可保存到相册或分享到微信/QQ 等社交平台

### 3.8 设置

设置页面允许自定义以下内容：

- **主题模式**：浅色 / 深色 / 跟随系统
- **每日提醒**：设置阅读提醒时间
- **年度目标**：设定每年计划阅读的书籍数量
- **数据管理**：数据导出/导入
- **隐私与法律**：用户协议、隐私政策、个人信息清单、第三方共享清单

## 四、常见问题

**Q：如何修改已添加的书籍信息？**
A：在书架页面长按书籍卡片，选择「编辑」修改书名、作者等信息。

**Q：打卡错过了怎么办？**
A：系统仅支持当天打卡，不支持补签。连续打卡天数以实际打卡记录为准。

**Q：我的数据如何备份？**
A：设置 → 数据管理 → 导出数据，可将全部数据导出为文件保存。更换设备后可通过「导入数据」恢复。

**Q：深色模式如何开启？**
A：设置 → 主题模式 → 选择「深色模式」或「跟随系统」。
